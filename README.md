# Poset Cover-Based Event Log Compressor

The poset cover-based event log compressor are scripts for performing poset cover based compression for event log (.XES) files.

## Setup
1. Install dependencies

2. Select dataset by editing `parser.py`

3. Run `parser.py`

4. If `parser.py` finishes running, results for filesizes can be checked using File Explorer.

5. Run `evaluation.py`
Note: `evaluation.py` is outdated, only decompression time is the metric used
